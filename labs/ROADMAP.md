# Hands-on lab roadmap

**All items below are planned. No lab completion or results are claimed.**

## 1. Windows connectivity and DNS

- Build a disposable test VM and record its OS and network mode.
- Capture a working baseline.
- Compare a disconnected adapter with the baseline.
- Query an existing test hostname and a nonexistent name.
- Restore configuration and verify the original task.
- Publish sanitized output and explain what each observation proves.

## 2. Active Directory account lifecycle

- Build an isolated domain and test client using properly licensed or authorized evaluation media.
- Create an ordinary test user and a test security group.
- Verify intended group membership and access.
- Demonstrate a password reset using test credentials.
- Document a controlled account lockout and recovery.
- Include topology, prerequisites, actual evidence, and limitations.

## 3. Printer support

- Create a local test queue or virtual printer.
- Observe a successful job.
- Pause the test queue and investigate the resulting symptom.
- Restore the queue and verify output.
- Write an incident report using the repository template.

## Definition of done

A lab is complete only when it includes:
- A reproducible environment and prerequisites
- The exact steps performed
- Actual, sanitized observations
- A clear distinction between expected and observed behavior
- Verification of recovery and cleanup
- Limitations and lessons learned

Publish lab reports as separate files and link them from the main README when complete.
